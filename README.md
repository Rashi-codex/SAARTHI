# 🌐 Saarthi – AI-Based Learning Guidance Platform

## 📌 Overview

Saarthi is a smart AI-based learning platform that provides personalized learning resources based on the user’s role and interests. It helps Children, Students, and Seniors find relevant educational content easily.

---

## 🚀 Features

* 🔐 User Login System
* 👥 Role-based Dashboard (Children / Student / Senior)
* 📚 Personalized Learning Resources
* 🤖 AI Chatbot for instant guidance
* 🎯 Subject-wise resource navigation
* 💾 SQLite Database Integration

---

## 🧠 AI Chatbot

The platform includes a simple AI chatbot that:

* Takes user input (text)
* Suggests learning resources
* Responds based on keywords like Python, AI, Math, etc.

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS
* **Backend:** Python (Flask)
* **Database:** SQLite
* **AI Logic:** JavaScript-based rule chatbot
